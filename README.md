# PRODIGY_DS_02
## Data
The data used was retrieved from [Emmanuel Odelami Kaggle Page](https://www.kaggle.com/datasets/eiodelami/disease-outbreaks-in-nigeria-datasets/code)
## Data Preparation
The data was cleaned by identifying and eliminating any null values, as well as checking for and removing duplicates. Several columns were standardized due to inconsistencies, where some values were recorded with initial capital letters while others were in lowercase. Additionally, the report_date column was converted to a datetime format.
## Exploratory Data Analysis
Exploratory Data Analysis (EDA) was conducted by visualizing the patterns and trends of different variables related to meningitis cases.
